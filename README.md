# SpaceX Falcon 9 First Stage Landing Prediction

## 🚀 Project Overview
SpaceX advertises Falcon 9 rocket launches on its website with a cost of **$62 million**, while other providers cost upwards of **$165 million** each. A significant portion of these savings is due to SpaceX's ability to reuse the first stage of the rocket. 

The primary goal of this project is to create a **machine learning pipeline** to predict if the first stage will land successfully. Determining the likelihood of a successful landing allows for more accurate launch cost estimations, providing valuable competitive intelligence for any company looking to bid against SpaceX for rocket launches.

## 📊 Methodology & Workflow
This project covers the end-to-end data science process, documented across a series of specialized Jupyter Notebooks:

1.  **Data Collection (API):** Gathering historical launch data via the SpaceX API.
2.  **Web Scraping:** Extracting Falcon 9 and Falcon Heavy launch records from Wikipedia.
3.  **Data Wrangling:** Cleaning and preprocessing the raw data for analysis.
4.  **Exploratory Data Analysis (SQL):** Using SQL to query the dataset and extract foundational insights.
5.  **Data Visualization:** Identifying trends and patterns using Pandas and Matplotlib.
6.  **Interactive Visual Analytics:** Mapping launch sites and analyzing landing outcomes with Folium.
7.  **Dashboard Development:** Building an interactive web application with Plotly Dash to explore the data dynamically.
8.  **Machine Learning Prediction:** Training and evaluating classification models to predict landing success.

## 🛠️ Technical Stack
*   **Languages:** Python (99.7%), SQL.
*   **Environment:** Jupyter Notebook .
*   **Libraries:** Pandas, Matplotlib, Folium, Plotly Dash, and Scikit-Learn.
